# Wolff, *Discursus praeliminaris de philosophia in genere* (1740)

Page transcription of the *Discursus praeliminaris*, printed at the head of Wolff's *Philosophia rationalis sive Logica* (2nd ed., 1740), made for the comparison with the opening paragraphs of Vattel's *Essai sur le fondement du droit naturel* (1747).

| File | Scans | Copy | Contents |
|---|---|---|---|
| `LOG40.json` | 104 pages (MDZ canvases 25–61 and 76–142) | Bayerische Staatsbibliothek, MDZ [bsb10008633](https://www.digitale-sammlungen.de/en/view/bsb10008633): Frankfurt and Leipzig, Officina Rengeriana, 1740 | §§ 1–171, cap. I–VI (printed pp. [1]–104) |

The MDZ copy images pp. 24–37 twice: canvases 62–75 repeat canvases 48–61. The second run is left out.

## Method

- Claude Sonnet subagents read each MDZ page image at 1300 px wide, with full-resolution crops of a zone on request (`tools/transcription/mdz_crop.py`). Prompt: `tools/transcription/TRANSCRIBE_PROMPT_LOG40.md`.
- Diplomatic rules and page format as for the *Philosophia practica universalis* (`texts/wolff-philosophia-practica-1738/README.md`). The small-type illustrative paragraphs are transcribed without markup.

## Checks

- The § markers run 1–171, each once.

## Known limits

- Some lines are blotted or show the reverse through. `notes_scan` names the pages.
- Not checked against a second copy.
