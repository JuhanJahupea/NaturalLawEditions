# Wolff, *Theologia naturalis, methodo scientifica pertractata*, pars prior (1739)

Page transcription of the end of cap. V, all of cap. VI (*De jure Dei in creaturas*) and the start of cap. VII of the first part, made for the reuse comparison with Vattel's *Essai sur le fondement du droit naturel* (1747). Vattel's note (b) to § 16 cites "Theol. Nat. P. I. §. 950".

Canvas numbers are printed page + 2.

## Method

- Claude Sonnet subagents read each MDZ page image at 1300 px wide, with full-resolution crops of a zone on request (`tools/transcription/mdz_crop.py`). Prompt: `tools/transcription/TRANSCRIBE_PROMPT_TN1.md`.
- Diplomatic rules and page format as for the *Philosophia practica universalis* (`texts/wolff-philosophia-practica-1738/README.md`).

## Checks

- The § markers run 948–1006, each once. A reader also set a marker for § 977 at the foot of p. 944, where no text of § 977 stands; it was removed.
